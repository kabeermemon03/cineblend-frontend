CineBlend Studios is designed to showcase creative services while providing clients with a seamless way to explore portfolios, submit project requests, and communicate throughout the development process.

---

# ✨ Overview

CineBlend Studios is more than a portfolio website—it's a complete digital platform built for freelancers and creative agencies.

The platform focuses on:

- 🎥 Video Production
- 🎨 Brand Identity
- 💻 Modern Web Development
- 📱 Responsive Design
- ☁ Cloud-Based Project Management
- ✉ Client Communication

Built with React, Firebase, and Framer Motion, the platform emphasizes performance, smooth animations, and a premium user experience.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/kabeermemon03/cineblend-frontend.git

cd cineblend-frontend
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
VITE_FIREBASE_MEASUREMENT_ID=
```

Run development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
